# Source of Truth

This GitHub repository is intended to be the canonical source for Seeker Lab plugin development.

Release artifacts must be built from committed repository contents. Do not edit generated ZIP files directly.

Authoritative package files:

- `plugin.json`
- `.codex-plugin/plugin.json`
- `skills/**`
- `assets/**`
- `README.md`
- `BRAND.md`

The plugin does not bundle the upstream `thewhiteh4t/seeker` project. It contains workflow Skills and safe helper scripts for authorized local/lab use.
