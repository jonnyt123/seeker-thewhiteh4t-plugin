# Security Policy

Seeker Lab is intentionally scoped to authorized, transparent local/lab workflows.

## Supported use

- localhost tests
- the user's own devices
- synthetic fixtures
- clearly consenting participants
- source review, diagnostics, privacy hardening, and defensive auditing

## Unsupported use

Do not use this plugin to create deceptive collection pages, conceal data collection, obtain another person's precise location/device data without informed consent, or configure covert exfiltration.

## Sensitive data

Treat precise coordinates, public IP addresses, device fingerprints, Telegram tokens, webhook URLs, generated CSV/KML files, and Seeker logs as sensitive. Do not commit them.
